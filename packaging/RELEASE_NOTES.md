# MiniMLX v0.1.1

This update improves model configuration and speculative decoding on Apple Silicon.

- Choose a compatible MTP or DFlash draft model for supported models.
- Fix MTP model selection and DFlash benchmark reporting for Qwen models.
- Show clear save confirmation and concise benchmark errors.
- Choose the interface language from the system preference on first launch; existing language settings are preserved.

## Install

Download `MiniMLX-0.1.1-arm64.dmg`, open it, and drag MiniMLX into Applications. Models are downloaded separately. An Apple Silicon Mac is required. The DMG is signed and notarized; the accompanying SHA-256 file can be used to verify it.
